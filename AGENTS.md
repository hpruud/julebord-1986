# Agent guidelines

Working preferences for AI agents contributing to this repo:

- If you are unsure, ask clarifying questions before acting.
- Do atomic commits — one logical change per commit and PR.
- Do not overcomplicate; prefer simple, minimal changes.
- Do not add a `Co-authored-by` trailer to commits.
- Use [Conventional Commits](https://www.conventionalcommits.org/) for commit messages and PR titles. Format: `type(scope): subject`. Common types: feat, fix, refactor, perf, style, docs, test, chore, revert. Use `!` for breaking changes.
